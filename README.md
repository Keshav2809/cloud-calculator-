# CloudCompare — Cloud Storage Comparison

A responsive BCA project website comparing Google Drive, Microsoft OneDrive and Dropbox.

## Technology
- HTML5
- CSS3
- JavaScript

## Pages
- index.html — Home
- compare.html — Interactive comparison table
- calculator.html — Storage calculator
- features.html — Feature analysis
- about.html — Project information and references

## How to run
1. Extract the ZIP.
2. Open the `CloudCompare` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. No backend or database is required.
